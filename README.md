# Git 練功房

給初學者的互動式 Git 練習：在模擬終端機輸入指令，右邊用圖形即時顯示發生了什麼事。

👉 **線上遊玩：https://hankhsu1969.github.io/git-practice/**

## 學什麼

9 堂小課，只教最基礎的指令：

`git init` · `git add` · `git commit` · `git status` · `git log` · `git restore` · `git branch` · `git switch` · `git merge`

## 特色

- **三個區域**：工作目錄 → 暫存區 → 儲存庫，檔案卡片會在區域之間飛來飛去
- **快照歷史圖**：commit、分支、HEAD 一目了然，移動時有動畫
- **白話解說**：每個指令執行後，用中文說明剛剛發生了什麼
- 檔案用畫面上的 ＋ / ✏️ 按鈕編輯，不需要學 shell 指令

## 在自己的電腦上執行

下載後直接用瀏覽器打開 `index.html` 即可，不需要安裝任何東西。
